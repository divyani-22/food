# 문제 정의 및 해결 전략

## 핵심 문제
1. 시각적으로 신선도를 판단하기 어렵다
2. 식재료 관리가 비효율적이다
3. 적절한 소비 타이밍 판단 어려움
4. 앱/AI 기반 자동화 솔루션 부족

## FreshGuard의 해결 전략
- EfficientNet 기반 신선도 판별
- 과일 종류(10종) + 신선도(2종: fresh/rotten) 멀티태스크 모델
- 신선도 확률 기반 3단계(fresh / normal / rotten) 후처리 규칙 적용
- 서버 기반 분석 후 앱에서 바로 결과 제공
- 향후 조리법 추천 및 다중 재료 분석 확장 가능
