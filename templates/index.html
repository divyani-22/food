System Architecture

FreshGuard AI 모델 구조 및 원리

카메라로 촬영한 과일 이미지를 기반으로 10종 과일 분류와 3단계 신선도를 한 번에 예측하는 멀티태스크 딥러닝 파이프라인

Backbone Network

EfficientNet-B0

ImageNet 사전학습 가중치를 활용하여 가볍고 빠른 연산속도와 높은 정확도를 보장합니다.

Head 1: Fruit Classification

10-Class Classifier

사과, 바나나, 파프리카, 당근, 오이, 망고, 오렌지, 감자, 딸기, 토마토 분류 (F1: 0.993).

Head 2: Freshness Score

3-Stage Rule Engine

p_fresh ≥ 0.7 (신선), ≤ 0.3 (부패), 중간 구간은 보통(소비 적기)으로 매핑 (F1: 0.981).

# FreshGuard Multitask Inference Flow:
1. [Input Image (224×224 RGB)] ➔ EfficientNet-B0 Backbone Feature Extractor
2. [Feature Vector (1280-dim)] ➔ Dropout(0.2)
3. ├─ Head_fruit(Linear) ➔ 10 Fruit Softmax ➔ argmax (과일 품종 판별)
4. └─ Head_fresh(Linear) ➔ 2-Class Softmax ➔ p_fresh 확률 산출
5. [Threshold Rule] ➔ fresh (≥0.7) / normal (0.3~0.7) / rotten (≤0.3)
