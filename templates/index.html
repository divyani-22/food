System Architecture

How the FreshGuard Model Works

A multitask deep learning pipeline that classifies 10 types of produce and predicts a 3-level freshness grade from a single photo.

Backbone Network

EfficientNet-B0

Uses ImageNet-pretrained weights for a lightweight, fast and accurate model.

Head 1: Fruit Classification

10-Class Classifier

Apple, banana, bell pepper, carrot, cucumber, mango, orange, potato, strawberry and tomato (F1: 0.993).

Head 2: Freshness Score

3-Stage Rule Engine

p_fresh ≥ 0.7 is fresh, ≤ 0.3 is rotten, and anything in between is normal (use soon) (F1: 0.981).

# FreshGuard Multitask Inference Flow:
1. [Input Image (224×224 RGB)] → EfficientNet-B0 Backbone Feature Extractor
2. [Feature Vector (1280-dim)] → Dropout(0.2)
3. ├─ Head_fruit(Linear) → 10 Fruit Softmax → argmax (produce type)
4. └─ Head_fresh(Linear) → 2-Class Softmax → p_fresh probability
5. [Threshold Rule] → fresh (≥0.7) / normal (0.3~0.7) / rotten (≤0.3)
